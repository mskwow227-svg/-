# 2026 산림레포츠 축제 오리엔티어링 대회 — 랜딩페이지

부천 진달래동산에서 열리는 **2026 산림레포츠 축제 오리엔티어링 대회**(2026.10.17 토) 홍보/안내용 정적 웹페이지입니다.

- 참가비 무료, 선착순 500명
- 가족·청소년·청년 7개 클래스
- 클래스 추천, 시상 시각화, 스탬프 투어, 주차 요금 계산기, FAQ 검색

## 기술 구성

빌드 도구·프레임워크 없이 **순수 HTML / CSS / JS**로만 만들어졌습니다. 저장소를 그대로 GitHub Pages에 올리면 배포됩니다.

```
index.html              # 마크업
assets/
  css/styles.css        # 디자인 토큰(CSS 변수) + 컴포넌트 스타일
  js/config.js          # ★ 대회 데이터 전부 (여기만 고치면 됨)
  js/main.js            # 렌더링 · 상호작용 로직
  favicon.svg
```

## 콘텐츠 수정하기

일시, 장소, 신청 폼 URL, 전화번호, 클래스 정보, 주차 요금, 부스, 시상 내역 등
**대부분의 텍스트/숫자는 [`assets/js/config.js`](assets/js/config.js) 한 파일에서 수정**합니다.

| 바꾸고 싶은 것 | 위치 |
|---|---|
| 날짜·시간·장소·모집 인원·전화·구글폼 링크 | `config.js` → `OL.event` |
| 주차 요금 체계 | `config.js` → `OL.parking` |
| 클래스 7종 (이름·대상·방식·설명) | `config.js` → `OL.classes` |
| 클래스 찾기 위저드 옵션·매칭 규칙 | `config.js` → `OL.finder` |
| 시상 내역 (상 이름·팀 수) | `config.js` → `OL.awards` |
| 체험 부스 | `config.js` → `OL.booths` |
| FAQ 질문·답변 | `index.html` 의 `#faq-list` (검색이 DOM 텍스트 기반이라 마크업 유지) |
| 색상·간격·폰트 | `assets/css/styles.css` 상단 `:root` |

> `config.js` 의 `dateISO` 는 항상 `+09:00`(KST)을 붙여 주세요. 안 붙이면 보는 사람의 시간대에 따라 카운트다운이 어긋납니다.

## 로컬에서 미리보기

빌드가 필요 없습니다. `index.html` 을 브라우저로 바로 열면 됩니다.
(정적 서버를 쓰고 싶다면 VS Code "Live Server" 확장 등 아무거나 가능)

## 배포 (GitHub Pages)

1. 이 저장소 → **Settings → Pages**
2. **Source**: `Deploy from a branch`
3. **Branch**: `main` / `/ (root)` → Save
4. 잠시 후 `https://<사용자명>.github.io/<저장소명>/` 에 게시됩니다.

`assets/` 경로는 모두 상대경로라 하위 경로 배포에서도 정상 동작합니다.
